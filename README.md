# ERP DevCon Engineering Repository

## Purpose

The ERP DevCon Engineering Repository is the central knowledge base for all company standards, product documentation, software architecture decisions, engineering guidelines and reusable development assets.

It serves as the single source of truth for all engineering-related documentation.

The repository is intended to support:

- Product Management
- Business Analysis
- Software Architecture
- Software Development
- Quality Assurance
- Technical Documentation
- Knowledge Management

---

---

# Documentation Principles

The repository follows the following principles:

- Business before Technology
- Information before Automation
- Platform Independence
- Single Source of Truth
- Separation of Concerns
- Documentation before Implementation
- Long-term Maintainability

---

# Repository Organization

## company-guide

Company-wide policies, engineering principles and documentation standards.

## architecture

Architecture principles and Architecture Decision Records (ADR).

## standards

Technical standards, coding guidelines and development conventions.

## templates

Standard document templates used throughout the organization.

## glossary

Business and technical terminology.

## products

Product-specific documentation.

Each product maintains its own documentation independent from company standards.

## libraries

Reusable software components and shared libraries.

## research

Research papers, evaluations, prototypes and technical investigations.

## archive

Historical documents that are no longer actively maintained.

---

# Working Process

Documentation is developed using feature branches.

Approved documentation is merged into the `main` branch.

Markdown files are considered the authoritative source.

Word and PDF documents are generated from the Markdown sources when required.
